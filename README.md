# GitHub Pages Personal Site

1ページ完結の個人サイトです。`index.html` をそのまま GitHub Pages に公開できます。

## Files
- `index.html` : ページ本体
- `styles.css` : スタイル
- `script.js` : スクロール時のフェードイン

## Customize
- Heroの名前・肩書き・リンクは `index.html` の `.hero` 内を編集してください。
- Projectsは `#projects` セクションの3カードを差し替えて使えます。
- PublicationsとContactは必要に応じて書き換えてください。

## Deploy
GitHub Pages を有効化し、リポジトリ直下を公開対象に設定すると表示されます。
